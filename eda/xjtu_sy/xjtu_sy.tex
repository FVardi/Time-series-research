\begin{itemize}
  \item Each cell is one bearing (LDK UER204, all new) run to failure at a constant condition.
        Number = lifetime in minutes = number of recordings; letters = failed element found
        after the test (OR outer race, IR inner race, B ball, C cage; ``all'' = IR, B, C and OR).
        Columns 1--5: bearing number within the condition.
  \item One recording per minute: 1.28\,s at 25.6\,kHz (32,768 samples), two channels
        (horizontal, vertical accelerometer), in g.
  \item Test stopped when the amplitude exceeded 10 times the maximum of the normal stage.
  \item Lifetimes range from 42 to 2538 minutes; no healthy-only bearing (every bearing
        starts healthy and ends failed). The fault element is not a label over time.
  \item Source: \texttt{BEARINGS}, \texttt{CONDITIONS} in \texttt{harness/data/xjtu\_sy.py}
        (intro Table 2).
\end{itemize}
