\begin{itemize}
  \item Each row is one new 61806-2RS bearing run to failure; Files = number of measurements.
  \item One measurement: 1.6\,s (204,800 samples at 128\,kHz, 102,400 at 64\,kHz), two
        accelerometers (A, C), stored as int16 ADC codes in V (D236).
  \item Speed and load are drawn at random per measurement within the ranges (description
        Table 2); bracketed = range, single value = constant. The dynamic load amplitude is
        sinusoidal for B01--B06 and Gaussian noise for B07--B17.
  \item Stop: vib.\ = $T_\text{vibration}$ (within [6, 10]\,g), temp.\ = $T_\text{temperature}$
        (110\,\textdegree C), -- = none given (B01 no criterion pre-set, B05 interrupted
        deliberately).
  \item Defects are those found after the test; most bearings have several.
  \item Source: \texttt{TABLE2}, \texttt{TABLE3} in \texttt{harness/data/paderborn\_rtf.py}
        (description Tables 2 and 3).
\end{itemize}
